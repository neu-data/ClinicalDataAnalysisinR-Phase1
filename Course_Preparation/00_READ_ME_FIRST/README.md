## What this week is for

This folder was sent to you about a week before the course so you can arrive **ready and relaxed** — not to test you. Nothing here is graded. The whole point is familiarity and confidence: get R and RStudio installed, learn your way around the screen, and gently practise with a real clinical dataset so the first evening feels comfortable rather than overwhelming. Plan for roughly **2–3 hours in total**, spread across the week in short, easy sittings. If you have never written a line of code in your life, you are exactly who this was written for. Take it slowly, and enjoy it.

## How to use this folder

Please work through things in this order:

1. **Read this file first** (you are here).
2. **Install the software** — open folder `01_Install_R_and_RStudio/`, follow the installation manual, then run `installation_test.R` to check everything works.
3. **Tour RStudio** — open folder `02_Getting_Started_with_RStudio/` and, when prompted, double-click `Clinical_Data_Analysis_PreCourse.Rproj` to open the whole project in RStudio.
4. **Work through the lessons** — go through folders `03` to `07` in order.
5. **Try the Exercises** — attempt the short exercises in `Exercises/`, then check yourself against `Solutions/`.
6. **Keep the reference material handy** — dip into `Cheat_Sheets/` and `Guides/` whenever you like.

There is no need to memorise anything. Reading, clicking along, and getting a feel for the tools is more than enough.

## A suggested week-before plan

Five short, calm evenings — about 20–40 minutes each. Adjust to suit you.

- **Evening 1 (~30–40 min):** Install R and RStudio (folder `01`) and run `installation_test.R` until you see the success message.
- **Evening 2 (~30 min):** Open the `.Rproj`, tour RStudio (folder `02`), then start R Basics (folder `03`).
- **Evening 3 (~30 min):** Work through Data Management (folder `04`) and load the clinical dataset.
- **Evening 4 (~30–40 min):** Explore the data with EDA (folder `05`) and attempt a couple of the Exercises.
- **Evening 5 (~20–30 min):** Skim Statistical Tests (folder `06`) and Regression (folder `07`), and finish any remaining Exercises.

If an evening runs short, just stop — you can always pick up where you left off.
